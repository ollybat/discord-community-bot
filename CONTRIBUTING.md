# Contributing

Thanks for helping improve the Free Discord Community Bot.

## Development

1. Fork the repository.
2. Create a branch for your change.
3. Copy `.env.example` to `.env` and use a test Discord application.
4. Run `npm install` and `npm start`.
5. Run `npm run check` before opening a pull request.

## Pull requests

- Keep commands focused and validate user input.
- Use least-privilege permissions.
- Do not include tokens, `.env` files, or private server data.
- Give users clear, friendly error messages.
- Update the README when adding commands.
